# Using homegym

A guide for the three of you training on the Marcy MWM-988. The app is the coach:
it shows how each exercise should look, counts you through your sets at the right
speed, and tells whoever is up next what to do with the pin.

> **So far only Day 1 (Push & core) has exercises.** Days 2–5 are on the week
> screen but say *Not built yet* and cannot be opened.

---

## 1. Getting it on the tablet

Open **https://keep-code-simple.github.io/homegym/** in the tablet's browser.

Then add it to the home screen:

- **iPad (Safari):** tap Share → **Add to Home Screen**.
- **Android (Chrome):** tap the ⋮ menu → **Add to Home screen** / **Install app**.

Opened from that icon, it runs full-screen like any other app.

**It works with the wifi off.** Once it has loaded, the whole app is saved on the
tablet. Nothing it does needs the internet: no accounts, no sign-in, nothing sent
anywhere.

The tablet's back gesture moves back one screen in the app. It will not throw you
out of the app.

### The first time you open it

You get **Four house rules**:

1. Form before weight. Always.
2. An adult is in the room whenever the stack is being used.
3. Never a single heavy rep to see what you can do.
4. If a joint hurts, stop that exercise for the day.

Tap **Got it**. The rules only show once on each tablet.

## 2. The week (home screen)

The home screen lists the five days. Today's day is marked **Today**. Each day
shows how many exercises it has and roughly how long it takes.

| Day | Focus              | Usual day |
| --- | ------------------ | --------- |
| 1   | Push & core        | Monday    |
| 2   | Pull & arms        | Wednesday |
| 3   | Legs & core        | Friday    |
| 4   | Full body, lighter | Saturday  |
| 5   | Move & stretch     | Tuesday, Thursday |

Sunday is a rest day.

Every day has three coloured dots, one for each of you: **red for Dad**, **blue for
Son 1**, **yellow for Son 2**. A dot fills in once that person has done that day.
**Tap a dot** to tick it. Tap it again to untick it if someone tapped by mistake.
The dots clear by themselves at the start of each week (Monday).

Tap a day to open it.

---

## 3. A day

The day screen shows:

- **Warm-up (3 min):** arm circles, 10 slow bodyweight squats, 8 cat-cow and one
  light set of the first exercise.
- **The exercises in order.** Each row shows the station it uses and what each of
  you does. For Day 1, Dad does 3 sets of 10–12 reps and the boys do 2 sets of
  12–15 reps. The plank is 3 × 40 seconds for Dad and 2 × 25 seconds for the boys.
- **Start session** at the bottom, which runs the whole day for all three of you
  (see [section 5](#5-session-mode--the-whole-day-together)).

Tap an exercise to learn it and practise it on its own.

The boys' numbers start lighter than Dad's on purpose. They are not targets to
catch up to.

## 4. Learning and practising one exercise

Open an exercise from the day screen to see everything about it.

### The demonstration

A side-view figure does the movement on a drawing of the machine. The plates
lift and the cable follows the hands. The figure moves at the speed you should
move:

| Label on screen  | What you do       | How long  |
| ---------------- | ----------------- | --------- |
| **Lift**         | Push or pull      | 1 second  |
| **Hold**         | Hold at the top   | 1 second  |
| **Lower slowly** | Let it back down  | 2 seconds |
| **Reset**        | Brief pause       | ½ second  |

The slow lowering is the most important part. Don't rush it.

Buttons under the figure:

- **Pause / Play** stops or starts the figure.
- **Half speed** slows everything down so you can see the details.
- **Show the mistake** replays the movement done **wrong**, in a different colour
  with a *Wrong* caption saying what went wrong. Tap **Show it correct** to go
  back. The drawn mistake is always one you can see from the side, like an arching
  back or a swinging body. Mistakes you can only see from the front, like elbows
  flaring out, are listed under *Watch out for* but not drawn.

If the tablet has "reduce motion" switched on, you see the start and finish
positions side by side instead of the moving figure.

Further down the page: **Setup** (how to adjust the machine), **Cues** (what to
think about), **Watch out for** (common mistakes) and **Breathing**.

### Running a set

1. **Pick who is lifting** with the name buttons (Dad / Son 1 / Son 2). The screen
   shows that person's set number and pin.
2. Tap **Start set**. Move in time with the figure.
3. The big number is your **rep count**. It goes up **at the top of the lift**,
   at the moment you'd say the number out loud. Under it you see the current step:
   *Lift*, *Hold*, *Lower slowly*, *Reset*. The set keeps going until your last
   slow lowering is finished.
4. When the set ends, a **rest countdown** starts ("Rest — others are lifting"),
   which lasts one minute. Tap **Ready now** to skip it.
5. After your last set it says **All sets done**. **Go again** starts over from
   set one.

**Stop** cancels a set partway through, and that set does not count. During a
set, *Show the mistake* and the speed buttons are hidden so nobody copies the
wrong version.

**Holds (the plank)** count down the seconds with **Hold still** in place of reps.

### Pins: numbers 1–15, not pounds

The **Pin weight** panel has a pin control for each of you on this exercise. The
**big number is the pin position**, the number printed on the stack, from **1 to
15**. Pounds are shown smaller underneath (10 lb per plate, so pin 4 = 40 lb).
Use **−** and **+** to change it.

- Each person's pin is **remembered separately for each exercise**, so the next
  time you open it your pin is already set.
- Changing someone's pin also switches the drawing to that person, so the stack
  in the picture matches the pin you set. This doesn't happen during a set.
- Everyone starts on a deliberately light pin. The first session is for finding
  your pin, not proving anything.
- **Raise it one plate at a time.** If you raise a pin by more than one plate
  since you opened the screen, the app warns you: *"That is 2 plates up from last
  time. Add one at a time."*

## 5. Session mode — the whole day together

There is one weight stack, so the three of you take turns. Tap **Start session** on
the day screen and the app runs the whole day as one rotation.

1. **Warm-up.** Do it together, then tap **Warmed up — start lifting**.
2. **Turns.** Each turn is one person doing one set of one exercise. The top shows
   which exercise you're on (e.g. *2/5*), the station, and how many sets are done
   out of the total. The three name tags show how many sets each person has left
   on this exercise, or *done*.
3. On your turn, check your pin (you can change it before you start), then tap
   **Start set**. The count works the same way as in practice. There is **no rest
   countdown** in a session, because your rest is the other two taking their
   turns. Tap **Skip [name]'s set** if someone is sitting this one out.
4. When the set is done, the **handoff** tells the room what happens next:
   - **Who is next** and, if the exercise changes, the name of the new one.
   - **What to do with the pin**, always spelled out:
     *"Move the pin from 5 to 2 (20 lb)."*, *"Pin stays at 4 (40 lb)."* or, when
     coming off a floor exercise onto the stack, *"Set the pin to 5 (50 lb)."*
   - **The setup steps for the new station** when the exercise changes.
   - If the same person goes twice in a row between two exercises, it says so.
     Setting up the next station is their rest.

   Then tap **[name] is up** to move on.
5. **Order.** For each exercise, everyone does set one before anyone does set two.
   Whoever has the most sets (Dad, on Day 1) goes first each round, so his extra
   set isn't straight after his last one. The boys drop out when their sets are
   done. Within an exercise, nobody ever lifts twice in a row.
6. **Finish.** After the last set, tap **Finish the session**. The app reminds you
   to put the stack down, the pin back to the top and the handles away. Then **tick
   off who actually trained** with the coloured dots.

**End session** at the top leaves the session at any point.

## 6. What the app remembers

Only three things are saved on the tablet:

- **Pin positions**, for each person and exercise.
- **The weekly ticks**: who has done which day this week.
- **Whether you've seen the house rules.**

Reps, sets, rest and hold times are **not saved**. They are gone once you leave
the screen. Nothing is sent off the tablet. Clearing the browser's website data
resets the app to the starting pins.

---

## 7. What is deliberately missing, and why

Some things aren't in the app on purpose:

- **No body weight, measurements, calories or BMI.** They have nothing to do with
  learning to move well, and they're not something the boys should be tracking.
  There is nowhere to type them in and nowhere to store them.
- **No records, personal bests or one-rep maxes, for anyone.** Saved numbers turn
  into a leaderboard, and a leaderboard turns into lifting too heavy with bad form.
  That's why reps and times are forgotten when you leave the screen, and why a
  house rule is *never a single heavy rep to see what you can do*.
- **No timer while you do reps.** A running clock makes people race, and the slow
  lowering is the point. Time only appears when time *is* the exercise (the plank
  countdown) and during rest.
- **No comparing the boys to Dad.** Their numbers start lighter, and nothing on
  screen asks them to match him.
- **Warnings about big pin jumps.** Adding weight faster than one plate at a time is
  how form breaks down.

A note on time: the home screen says "thirty-ish minutes", but Day 1 is five
exercises and seven sets each, with a pin change between every set. Expect around
40 minutes. The day screen shows the app's own estimate.

## For developers

This guide covers using the app. For how it's built:

- [`README.md`](../README.md): product shape, deployment, animation and set-runner
  design.
- [`CLAUDE.md`](../CLAUDE.md): hard constraints (MWM-988 or bodyweight only, fully
  offline, relative URLs only), pose authoring, and the product rules enforced in
  code.

```sh
npm install
npm run dev        # dev server on http://localhost:5173
npm run build      # type-check, build and generate the offline service worker
npm run preview    # serve the built app
npm run lint       # oxlint
npm run check      # rep-timing and set-runner assertions (exits non-zero on failure)
npm run smoke      # render every screen as a crash check
npm run poses      # render every Day 1 pose to /tmp/posesheet.svg
npm run icons      # regenerate home-screen icons (macOS only)
```

Pushing to `main` deploys to GitHub Pages after lint, `check` and `smoke` pass.
